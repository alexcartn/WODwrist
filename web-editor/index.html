Format
  • Optional name line: # Fran
  • First line: AMRAP 12, EMOM 10, E2MOM 20, FOR TIME cap 15, 3 ROUNDS FOR TIME, TABATA 8x20/10
  • One movement per line: 10 wall balls, 200m run, 15 cal row, 30s plank. Loads (kg by default): 21 thrusters 43/30, (24), @100, 135/95 lb
  • Rep scheme for For time: 21-15-9
  • EMOM: lines rotate minute by minute, or use odd: / even: / min 3:. Join movements done in the same minute with +
  • Lines can also be separated by ; (that is what the watch settings field uses)
  • More formats: EVERY 2:30 x 6, every 90 sec for 12 min, DEATH BY burpees (1 rep the first minute, +1 each minute, ends at the first miss), open ladder in an AMRAP: 3-6-9-...
  • Class plan: separate the parts (warm-up, strength, metcon) with a line ---. The coach watch runs them back to back
